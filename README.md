# 灰鹭俱乐部 · Grey Heron Club

**把长对话换成选择。** 一个无需打字的中文心理博弈游戏原型，用封签、查验与复盘串起完整体验。

[进入游戏](https://grey-heron-club-d4fdqiio01c3fd1b-1406949249.tcloudbaseapp.com/) · [项目介绍](https://grey-heron-club-d4fdqiio01c3fd1b-1406949249.tcloudbaseapp.com/project/index.html) · [介绍与简历文案](public/project/project-copy.md)

![灰鹭俱乐部实机](public/project/entrance.webp)

## 为什么做这个项目

这是一次个人兴趣驱动的玩法探索：用简单操作承载心理博弈，保留试探、选择与揭晓的乐趣。角色与场景提供代入感，规则让行动有代价，赛后记录与原理笔记帮助玩家理解自己的判断。

## 当前可玩内容

- **《封签》八轮对局**：双方各出签四次，每人仅有两次查验机会。
- **四位原创角色**：不同背景、场景台词与轻量策略偏好；所有角色使用同一动作集合和信息权限。
- **选择式互动**：出真签或假签、选择短句或沉默、查验或放行，全程无需输入长文。
- **反馈与学习**：逐轮结果、整局轨迹、四类博弈原理及单轮期望收益试算。
- **三场景界面**：门厅、圆桌大厅、俯视书桌，像素人物、可翻阅书页与独立纸签物件。
- **持久化**：本地 SQLite 或腾讯云 CloudBase，支持刷新恢复对局。

![封签操作](public/project/play.webp)

当前对手是**规则策略 + 预写台词**，不调用大模型 API。原型不包含真人匹配、付费筹码或完整情绪系统。《最后证词》《盲池》《第三席》仍在筹备中。复盘不承诺每轮全局最优解，也没有经过真实用户留存或体验提升验证。

## 立即在本地运行

需要 Node.js 24+ 和 npm。

```sh
git clone https://github.com/a-little-snack-123/grey-heron-club-demo.git
cd grey-heron-club-demo
npm ci
npm run dev
```

打开 `http://127.0.0.1:4173`；项目介绍为 `/project/index.html`。

```sh
npm test
npm run build
npm start
```

`npm run build` 自动运行素材边缘及配色检查，再检查 TypeScript 并构建。`npm start` 使用本地生产构建。对局保存在 `data/games.sqlite`，本机访问凭证保存在浏览器；清理浏览器数据后本原型无法找回凭证。

## 《封签》规则

八轮后比较总分，可负分、可平局。表中得分按“出签者 / 查验者”排列。

| 封签 | 放行 | 查验 |
|---|---|---|
| 真签 | +2 / +1 | +3 / −1 |
| 假签 | +4 / −2 | −3 / +2 |

封好后不可更换，揭晓后才公开真假。查验次数有限，不能仅用当前收益判断整局策略。试算页面中的概率由玩家设定，不是系统从台词中识别出的真实概率。

## 实现与结构

```text
React 界面 → HTTP 接口 → 服务端规则引擎 → SQLite / CloudBase
                           ↓
                    只返回允许公开的 GameView
```

| 路径 | 内容 |
|---|---|
| `src/components/`、`src/ui/` | 场景、书页、人物与导航 |
| `src/games/seal/` | 封签界面、复盘与原理 |
| `src/content.ts` | 原创角色、场景台词、创作参考 |
| `server/engine.ts` | 规则、混合策略、公开视图 |
| `server/index.ts` | 本地 Express / SQLite 接口 |
| `cloud/` | CloudBase 适配 |
| `tests/` | 规则、信息隔离、接口与并发检查 |
| `public/project/` | 可嵌入个人网站的静态项目介绍 |

服务端裁决封签与得分，NPC 仅读取公开观察；接口包含访问凭证、版本冲突检查与重复提交保护。测试覆盖八轮终局、资源限制、隐藏信息、持久化和云端并发。有限轮数策略与公开历史调整不代表已经证明达到高水平人类玩家强度。
